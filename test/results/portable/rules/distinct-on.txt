distinct-on (error): DISTINCT ON

DISTINCT ON (a) keeps one row per value of a on PostgreSQL only.

SQLite, MySQL and MariaDB report a syntax error. Window functions say the same
thing on all four (SQLite 3.25, MySQL 8.0 and MariaDB 10.2 and later).

Given:
    CREATE TABLE t (a INTEGER, b INTEGER);
    INSERT INTO t VALUES (1, 5), (1, 3), (2, 4)

Example:
    SELECT DISTINCT ON (a) a, b FROM t ORDER BY a, b

    SQLite 3.45.1        error: near "ON": syntax error
    PostgreSQL 16.15     1, 3; 2, 4
    MySQL 8.0.46         error: You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the r...
    MariaDB 10.11.14     error: You have an error in your SQL syntax; check the manual that corresponds to your MariaDB server version for the...

The same on every engine:
    SELECT a, b FROM (SELECT a, b, ROW_NUMBER() OVER (PARTITION BY a ORDER BY b) AS n FROM t) AS s WHERE n = 1 ORDER BY a

    SQLite 3.45.1        1, 3; 2, 4
    PostgreSQL 16.15     1, 3; 2, 4
    MySQL 8.0.46         1, 3; 2, 4
    MariaDB 10.11.14     1, 3; 2, 4

Number the rows of each group and keep the first: SELECT a, b FROM (SELECT a,
b, ROW_NUMBER() OVER (PARTITION BY a ORDER BY b) AS n FROM t) AS s WHERE n =
1.
