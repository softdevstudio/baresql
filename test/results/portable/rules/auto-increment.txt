auto-increment (error): Numbering new rows

Every engine numbers new rows with its own syntax, and SERIAL, which works on
PostgreSQL, MySQL and MariaDB, leaves the column NULL on SQLite.

AUTO_INCREMENT belongs to MySQL and MariaDB, AUTOINCREMENT to SQLite, and
GENERATED BY DEFAULT AS IDENTITY to PostgreSQL. SERIAL is PostgreSQL's as
well, and MySQL and MariaDB accept it as BIGINT UNSIGNED NOT NULL
AUTO_INCREMENT UNIQUE. SQLite accepts any type name, so SERIAL is only a name
there and the column stays NULL: SQLite numbers rows for a column declared
INTEGER PRIMARY KEY and nothing else.

Example:
    CREATE TABLE t (id SERIAL PRIMARY KEY, x INTEGER);
    INSERT INTO t (x) VALUES (5);
    SELECT id FROM t

    SQLite 3.45.1        NULL
    PostgreSQL 16.15     1
    MySQL 8.0.46         1
    MariaDB 10.11.14     1

No column definition numbers rows on all four engines. Keep one schema file
per engine for these tables, or let the application assign the ids.

                      SQLite PostgreSQL MySQL MariaDB
SERIAL                NULL   1          1     1
BIGSERIAL             NULL   1          no    no
AUTO_INCREMENT        no     no         yes   yes
AUTOINCREMENT         yes    no         no    no
GENERATED AS IDENTITY no     yes        no    no
IDENTITY(1, 1)        yes    no         no    no
