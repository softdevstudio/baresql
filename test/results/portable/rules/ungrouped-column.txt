ungrouped-column (error): Columns missing from GROUP BY

A selected column that is neither grouped nor aggregated takes its value from
any row of the group on SQLite and MariaDB; PostgreSQL and MySQL refuse the
query.

SELECT a, b FROM t GROUP BY a asks for one b per group without saying which.
SQLite and MariaDB pick one (MariaDB's default mode leaves out
ONLY_FULL_GROUP_BY). PostgreSQL and MySQL stop with an error, unless the
grouped column is the table's primary key, which fixes every other column of
that table.

Given:
    CREATE TABLE t (a INTEGER, b INTEGER);
    INSERT INTO t VALUES (1, 1), (1, 2)

Example:
    SELECT a, b FROM t GROUP BY a

    SQLite 3.45.1        1, 1
    PostgreSQL 16.15     error: column "t.b" must appear in the GROUP BY clause or be used in an aggregate function
    MySQL 8.0.46         error: Expression #2 of SELECT list is not in GROUP BY clause and contains nonaggregated column 'baresql_compare.t.b'...
    MariaDB 10.11.14     1, 1

The same on every engine:
    SELECT a, MAX(b) FROM t GROUP BY a

    SQLite 3.45.1        1, 2
    PostgreSQL 16.15     1, 2
    MySQL 8.0.46         1, 2
    MariaDB 10.11.14     1, 2

Add the column to GROUP BY, or say which value you want with an aggregate such
as MAX(b).
