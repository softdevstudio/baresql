cast-to-float (error): CAST to a floating point type

CAST(x AS DOUBLE PRECISION) fails on MariaDB, CAST(x AS DOUBLE) on PostgreSQL,
and CAST(x AS FLOAT) gives a 4-byte float on MySQL and MariaDB.

No floating point type name works in CAST on all four engines with the same
meaning. MariaDB takes DOUBLE and FLOAT in CAST but not DOUBLE PRECISION or
REAL, and PostgreSQL has no type called DOUBLE. FLOAT runs everywhere, but it
means an 8-byte float on SQLite and PostgreSQL and a 4-byte one on MySQL and
MariaDB, so CAST(0.1 AS FLOAT) * 3 is 0.30000000000000004 on the first two and
0.30000000447034836 on the others.

Example:
    SELECT CAST(0.1 AS FLOAT) * 3

    SQLite 3.45.1        0.30000000000000004
    PostgreSQL 16.15     0.30000000000000004
    MySQL 8.0.46         0.30000000447034836
    MariaDB 10.11.14     0.30000000447034836

The same on every engine:
    SELECT ROUND(0.1 * 3, 4)

    SQLite 3.45.1        0.3
    PostgreSQL 16.15     0.3000
    MySQL 8.0.46         0.3
    MariaDB 10.11.14     0.3000

There is no portable CAST to a float. When a fraction is all that's needed,
multiply by 1.0 (see integer-division) and round the result to the digits you
need.

                 SQLite             PostgreSQL         MySQL              MariaDB
DOUBLE PRECISION yes                yes                yes                no
REAL             yes                yes                yes                no
DOUBLE           yes                no                 yes                yes
FLOAT            0.3000000000000... 0.3000000000000... 0.3000000044703... 0.3000000044703...
