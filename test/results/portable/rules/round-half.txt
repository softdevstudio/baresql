round-half (warning): ROUND of a floating point half

ROUND of the floating point value 2.5 is 3 on SQLite and 2 on PostgreSQL,
MySQL and MariaDB.

Exact numbers, such as the literal 2.5 or a DECIMAL column, round half away
from zero on every engine. Floating point values don't. SQLite still rounds
2.5 up to 3, while PostgreSQL, MySQL and MariaDB round a float that is exactly
half way to the even neighbour, so 2.5 becomes 2 and 3.5 becomes 4. PostgreSQL
also has no ROUND(x, digits) for floats.

Given:
    CREATE TABLE t (x DOUBLE PRECISION);
    INSERT INTO t VALUES (2.5), (3.5)

Example:
    SELECT ROUND(x) FROM t ORDER BY x

    SQLite 3.45.1        3.0; 4.0
    PostgreSQL 16.15     2; 4
    MySQL 8.0.46         2; 4
    MariaDB 10.11.14     2; 4

The same on every engine:
    SELECT ROUND(CAST(x AS DECIMAL(10, 2))) FROM t ORDER BY x

    SQLite 3.45.1        3.0; 4.0
    PostgreSQL 16.15     3; 4
    MySQL 8.0.46         3; 4
    MariaDB 10.11.14     3; 4

Round an exact number: ROUND(CAST(x AS DECIMAL(10, 2))) rounds half away from
zero everywhere. Amounts that get rounded are better kept in DECIMAL columns
in the first place.

            SQLite   PostgreSQL MySQL MariaDB
ROUND(x)    3.0; 4.0 2; 4       2; 4  2; 4
ROUND(x, n) 3.0; 4.0 no         2; 4  2; 4
