function-not-everywhere (error): Functions that exist on some engines only

Many everyday functions are missing on at least one engine: IFNULL on
PostgreSQL, LEFT and NOW on SQLite, STRING_AGG on MySQL and MariaDB.

Each function in the table was called on all four engines, and the table shows
where the call ran and what to write instead.

Example:
    SELECT IFNULL(NULL, 'x')

    SQLite 3.45.1        'x'
    PostgreSQL 16.15     error: function ifnull(unknown, unknown) does not exist
    MySQL 8.0.46         'x'
    MariaDB 10.11.14     'x'

The same on every engine:
    SELECT COALESCE(NULL, 'x')

    SQLite 3.45.1        'x'
    PostgreSQL 16.15     'x'
    MySQL 8.0.46         'x'
    MariaDB 10.11.14     'x'

Prefer the functions all four engines have: COALESCE, NULLIF, CASE, SUBSTR,
REPLACE, TRIM, UPPER, LOWER, ABS, ROUND, and CONCAT (SQLite from 3.44).
